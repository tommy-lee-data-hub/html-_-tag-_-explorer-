HTML Tag Explorer — Website Project

Files:
- index.html: page structure and HTML element demonstrations
- style.css: responsive design and visual styling
- script.js: tag search, sample form response, quiz interaction

How to open:
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox, or another browser.
3. Keep all three files in the same folder.
4. To edit it, open index.html, style.css, or script.js in a code editor.

Notes:
- The form is a front-end demo and does not send data to a server.
- The multimedia section shows code examples; add your own media files to play actual audio/video.
- The page demonstrates many tags, but not every rare HTML element is useful or appropriate on one website.
