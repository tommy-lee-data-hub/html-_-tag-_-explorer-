Does HTML alone make a complete website?

HTML provides the structure. CSS improves the design, JavaScript can add interaction, and server-side code or a service may be needed for accounts, payments, and saving form submissions.

What should I learn next?

Practise HTML first, then learn CSS for responsive layouts and JavaScript for interactive features. Build small projects as you learn.
